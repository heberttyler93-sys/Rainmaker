# UFC Phase Transition

A statistical framework for modelling UFC fight outcomes, detecting intra-card
correlations, and investigating whether fight results on the same event are
independent — or whether something more structured (a "phase transition") is
happening beneath the surface.

---

## Research Question

When a heavy favourite loses in the opening fight of a UFC card, does the
probability of upsets in subsequent fights increase? Do fight outcomes cluster
in ways that the naive independence assumption cannot explain?

This project answers that question through a four-layer modelling stack:

1. **Bradley-Terry ratings** — learn each fighter's latent skill from historical
   win/loss data.
2. **Gaussian copula** — model the joint distribution of all fights on a card,
   allowing for non-zero intra-card correlation.
3. **Proper scoring rules** — evaluate predictions with Brier score, log-loss,
   and calibration curves.
4. **Residual analysis** — detect systematic over- and under-confidence, group
   errors by event, weight class, or any metadata column.

## Framework Reference

### Layer 1 — `BradleyTerry` (`src/bradley_terry.py`)

Assigns every fighter a latent log-skill parameter β. The win probability for
fighter *i* against fighter *j* is:

```
P(i beats j) = sigmoid(β_i − β_j)
```

Parameters are estimated by maximising a time-weighted log-likelihood with L2
regularisation (via L-BFGS-B), then centred so ratings sum to zero.

```python
from src.bradley_terry import BradleyTerry

bt = BradleyTerry()
bt.fit(fight_list, time_weights=weights)   # fight_list: [(winner, loser), ...]
bt.win_probability("Jon Jones", "Stipe Miocic")
bt.leaderboard()                           # DataFrame sorted by β
```

Key details:
- `time_weights` — pass exponentially decaying weights (see `utils.time_decay_weights`)
  to down-weight old fights.
- `leaderboard()` — returns a DataFrame with `Fighter`, `Beta`, and
  `Win% vs avg` (probability of beating an average opponent).

---

### Layer 2 — `GaussianCopula` (`src/copula.py`)

Models the joint distribution of all fights on a card using a Gaussian copula
with correlation matrix **R**. When **R = I** the model reduces to naive
independence.

```python
from src.copula import GaussianCopula

# Uniform correlation across all fights on the card
cop = GaussianCopula(n_fights=12, rho_matrix=None)   # identity → independence

# With estimated intra-card correlation rho
import numpy as np
n = 12
R = np.full((n, n), 0.15)
np.fill_diagonal(R, 1.0)
cop = GaussianCopula(n, R)

fight_probs = [0.65, 0.72, 0.58, ...]   # P(fighter1 wins) for each fight

cop.simulate_card(fight_probs, n_simulations=10_000)     # (10000, n) binary array
cop.favorites_sweep_probability(fight_probs)             # P(all favorites win)
cop.correlation_effect(fight_probs)                      # DataFrame across rho values
```

`correlation_effect()` is useful for sensitivity analysis — it shows how much
the sweep probability and the naive product diverge as ρ increases.

---

### Layer 3 — `ScoringRules` (`src/scoring.py`)

Strict proper scoring rules for evaluating probabilistic predictions.

```python
from src.scoring import ScoringRules

ScoringRules.brier_score(predictions, outcomes)          # lower is better, 0 = perfect
ScoringRules.log_loss(predictions, outcomes)             # lower is better
ScoringRules.calibration_curve(predictions, outcomes)    # DataFrame by probability bin
ScoringRules.baseline_brier(outcomes)                    # Brier of a naive 0.5 model
```

Skill over baseline is `baseline_brier − brier_score`: a positive number means
the model beats the 50/50 baseline.

---

### Layer 4 — `ResidualAnalyzer` (`src/residual.py`)

Wraps predictions and outcomes and surfaces systematic errors.

```python
from src.residual import ResidualAnalyzer

ra = ResidualAnalyzer(predictions, outcomes, metadata=fights_df)
ra.summary()                    # prints Brier, log-loss, skill, residual stats
ra.plot(save_path='out.png')    # 3-panel diagnostic figure
ra.group_by('weight_class')     # mean/std/count residual by any metadata column
```

The three-panel diagnostic shows:
- **Residuals vs. predicted probability** — checks for systematic over/underconfidence.
- **Residual distribution** — should be centred at zero.
- **Calibration curve** — predicted probabilities vs. actual win rates per bin.

## Key Concepts

**Phase transition** — In statistical physics, a phase transition is a sharp
change in macroscopic behaviour driven by a microscopic parameter crossing a
threshold. The analogy here: as average favourite strength increases, does the
variance of upset counts deviate from what independence predicts? If upsets
cluster (more variance than Binomial), that is evidence for positive intra-card
correlation — a "soft" phase transition from independent fights to correlated
outcomes.

**Cascade effect** — `plot_conditional_upset` asks: conditional on *k* upsets
having already occurred on a card, is the next fight more or less likely to be
an upset? A rising conditional probability would suggest a momentum or
crowd/judge sentiment effect.

**Copula vs. naive independence** — The naive prediction for "all 12 favourites
win" is the product of 12 individual probabilities. The copula corrects this
when ρ > 0, generally increasing the probability of extreme outcomes (all
favourites win *or* all underdogs win) relative to the independence baseline.
